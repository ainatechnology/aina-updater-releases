# aina-updater v0.1.0-beta

🎉 **Initial Beta Release**

The first public beta of aina-updater – the macOS Application Update Manager.

## ✨ Features

### App Management
- 🔍 Scan installed applications in `/Applications` and `~/Applications`
- 📋 Detect versions, bundle IDs, and installation sources
- 🏷️ Identify App Store, Homebrew, and direct-download apps

### Update Checking
- ✨ **Sparkle/AppCast** feed support for most Mac apps
- 🐙 **GitHub Releases** integration
- 🍺 **Homebrew Cask** version checking
- ⚙️ Custom feed URLs per app

### Update Installation
- 📦 Download updates with progress display
- 💾 Support for DMG, ZIP, and PKG installers
- 🔄 Automatic backup before installation

### Uninstall
- 🗑️ Remove apps with all related files
- 🔍 Find caches, preferences, and support files
- 👀 Interactive mode for selective cleanup

### Web UI
- 🌐 Beautiful dashboard at `http://localhost:3000`
- 📊 Statistics and problem detection
- 🌙 Dark/Light mode

### Configuration
- ⚙️ TOML-based configuration
- 📝 Per-app overrides
- 💾 SQLite database for caching

## 📥 Installation

### Apple Silicon (M1/M2/M3)
```bash
curl -LO https://github.com/aina-technology/aina-updater-releases/releases/download/v0.1.0-beta/aina-updater-v0.1.0-beta-macos-arm64.zip
unzip aina-updater-v0.1.0-beta-macos-arm64.zip
sudo mv aina-updater /usr/local/bin/
```

### Intel Mac
```bash
curl -LO https://github.com/aina-technology/aina-updater-releases/releases/download/v0.1.0-beta/aina-updater-v0.1.0-beta-macos-x64.zip
unzip aina-updater-v0.1.0-beta-macos-x64.zip
sudo mv aina-updater /usr/local/bin/
```

## 🚀 Quick Start

```bash
# Scan all apps
aina-updater scan

# Check for updates
aina-updater check-all

# Start Web UI
aina-updater serve
```
